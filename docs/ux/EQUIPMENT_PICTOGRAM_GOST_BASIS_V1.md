# EOD equipment pictograms — ГОСТ-основа V1

**Статус:** `CANONICAL REFINEMENT / DIRECTION A`

**Нормативная основа:** ГОСТ Р 56303-2014 в редакции с Изменением № 1,
введённым в действие 01.06.2023.

## 1. Назначение

Документ определяет границу между интерфейсными пиктограммами типов оборудования
в ЭОД и полноценными УГО нормальных схем электрических соединений.

Интерфейсные пиктограммы помогают распознать тип объекта в меню, дереве,
реестре или карточке. Они не заменяют инженерное УГО и не являются нормативным
фрагментом схемы. Для самих схем применяются обозначения и правила
ГОСТ Р 56303-2014, включая приложение Б.

## 2. Правило адаптации

```text
узнаваемая форма УГО
+ сохранённая электротехническая семантика
+ адаптация к сетке 24 × 24
+ единый интерфейсный stroke
+ проверка на 18 / 20 / 24 / 32 px
```

Допускается упрощать второстепенные детали и корректировать пропорции ради
читаемости. Запрещено менять базовую топологию обозначения, подменять
электротехнический смысл бытовой метафорой или выдавать UI-пиктограмму за УГО.

## 3. Источники форм

| Пиктограмма ЭОД | Основа |
|---|---|
| `icon-equipment-line` | линия электрической связи, раздел 4.5 |
| `icon-equipment-cable` | концевая муфта КЛ, таблица Б.1, позиция 4 |
| `icon-grounding` | заземление, таблица Б.1, позиция 5 |
| `icon-equipment-transformer` | трансформатор двухобмоточный, позиция 6 |
| `icon-equipment-busbar` | шина и отводы, позиции 1–3 |
| `icon-equipment-breaker` | выключатель, позиции 25–26 |
| `icon-equipment-disconnector` | разъединитель, позиции 31–32 |
| `icon-equipment-ground-switch` | заземляющий разъединитель, позиции 33–34 |

`icon-equipment-breaker` использует квадрат аппарата. Линии присоединения
заканчиваются на верхней и нижней гранях квадрата и не пересекают его. Это
разводит выключатель с вытянутым обозначением плавкого предохранителя.

`icon-equipment-ground-switch` показывает отключённый заземляющий разъединитель:
фиксированный контакт, отдельный наклонный подвижный контакт с видимым разрывом
и соединение основания подвижного контакта с узнаваемым знаком земли.

`icon-equipment-portable-ground` показывает три фазных зажима, гибкие
проводники, общую точку соединения и спуск на заземление, но не объявляется
самостоятельным УГО из таблицы Б.1.

Интерфейсные пиктограммы не заменяют инженерное УГО и не используются как
нормативные фрагменты схем.

## 4. Acceptance gate

1. Светлая и тёмная темы.
2. Размеры `18 / 20 / 24 / 32 px`.
3. Отсутствие обрезания в `24 × 24`.
4. Различимость выключателя, предохранителя, разъединителя и заземляющего
   разъединителя.
5. Сохранение всех canonical symbol IDs.
