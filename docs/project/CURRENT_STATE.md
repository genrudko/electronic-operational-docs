## 1. Статус проекта

Проект является независимым демонстрационным прототипом электронной оперативной документации для энергетики. Инициатива не является официальным поручением работодателя. Производственные серверы, фактические оперативные записи и реальные персональные данные в разработке не используются.

Целевой текущий рубеж — внутренний рабочий прототип всей оперативной документации; следующий рубеж — полностью функциональная демонстрационная версия. После DOCS-001 утверждённый план подлежит отдельной сверке с фактической реализацией и может быть скорректирован.

## 6. Текущий процесс разработки

Нормальный процесс больше не использует скачиваемые Python patch-файлы:

1. ассистент создаёт изменение в отдельной ветке GitHub;
2. CI проверяет изменение;
3. VPS development получает ветку через `git pull --ff-only`;
4. выполняются refresh/check/test/status;
5. пользователь проводит предметную и визуальную приёмку;
6. merge разрешается только пользователем;
7. preview синхронизируется после merge.

Пользователь исключён из механической части программирования, но сохраняет постановку задачи и приёмку.
