# Repository documentation structure

- `docs/project` — state, release plan, checklist and change control;
- `docs/product` — scope, module map, sequence, source coverage and decisions;
- `docs/modules` — 27 specialized contracts;
- `docs/evidence` — legal, authority, competitor and source matrices;
- `docs/ux` — shared Direction A contract;
- `docs/work-items` — execution packages;
- `docs/decisions` — accepted/candidate decisions;
- `docs/research` — evidence input.

`ROADMAP.md`, `OPEN_ITEMS.md` and project-level `MODULE_MAP.md` are compatibility pointers only.
