# ЭОД — открытые вопросы и отложенные задачи

## Визуальная проверка Patch 011.7 Repair 2

- каталог форм показывает документ, раздел и приложение;
- кнопка ручного создания типа отсутствует;
- техническая тестовая схема не позволяет создать или изменить запись;
- системные коды и SHA-256 скрыты из обычного слоя;
- карточка записи и история читаемы;
- обязательный комментарий перехода имеет явную подсказку;
- множественный выбор фильтруется и работает обычным щелчком;
- пустые строки внутреннего formset не создают ложных ошибок.

## Patch 011.8 — Structured Journals Pack

Создать формы строго по утверждённым источникам:

- журнал заявок;
- журнал распоряжений;
- журнал дефектов оборудования;
- журнал ввода оборудования в работу;
- журнал РЗА и телемеханики;
- журнал выдачи и возврата ключей;
- журнал учёта работ по нарядам и распоряжениям.

Для каждого журнала обязательны таблица трассировки «графа → пункт/приложение», отдельная рабочая форма и специализированные правила. Формы ключей и работ по нарядам не заполняются по памяти: сначала требуется точный утверждённый источник.
