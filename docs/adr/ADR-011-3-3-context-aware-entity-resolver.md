# ADR-011.3.3 — Контекстное разрешение сущностей и упрощённый ввод времени

## Статус

Принято для независимого прототипа.

## Проблема

Автосвязи Patch 011.3.2 сопоставляли независимые подстроки. Это позволяло
создать две ссылки для одного человека (`ДЭМ` и `Иванову`), не учитывало
эквивалентность `КТП-1` и `КТП-01` и использовало статический каталог записей,
который устаревал после добавления строки в текущей вкладке.

## Решение

1. Resolver собирает кандидатов по контексту и выбирает непересекающиеся
   диапазоны с приоритетом составной и наиболее конкретной сущности.
2. Должность вместе с фамилией считается единым упоминанием сотрудника;
   отдельное название должности не участвует в автоматическом связывании.
3. Обозначения оборудования нормализуют пробелы, дефисы, `№`, ведущие нули и
   типовые кириллическо-латинские варианты букв.
4. Каталог связанных записей пересобирается из актуальных строк DOM перед
   каждым поиском. Временная ссылка создаётся только при контекстной конструкции
   (`за 11:20`, `по записи 11:20` и аналогичной) и однозначном предыдущем
   совпадении текущей даты.
5. Пользовательская настройка упрощённого времени хранится в
   `InterfacePreference`. При включении `1120` преобразуется в `11:20` как в
   поле времени записи, так и в её тексте. Годы, номера документов и
   технические обозначения не преобразуются.

## Последствия

- один текстовый диапазон не может получить вложенные или дублирующие ссылки;
- новые и отредактированные строки доступны resolver без перезагрузки;
- пользователь самостоятельно включает ускоренный ввод времени;
- добавляется миграция `organizations.0006`, не затрагивающая оперативные
  записи и их исторические данные.
