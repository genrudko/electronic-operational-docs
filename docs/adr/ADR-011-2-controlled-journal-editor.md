# ADR-011.2 — контролируемое ядро редактора оперативного журнала

## Статус

Принято для независимого демонстрационного прототипа.

## Контекст

Черновая запись ранее хранилась только как обычный текст. Для дальнейших
шаблонов и семантических элементов требуется структурированный формат, но
произвольный HTML в оперативном журнале недопустим.

## Решение

Черновая запись хранит две согласованные проекции:

- `editor_payload` — версионированный JSON-документ;
- `content` — обязательная читаемая текстовая проекция.

Допустимы только:

- абзацы;
- маркированные списки;
- нумерованные списки;
- полужирное начертание;
- подчёркивание.

HTML не сохраняется. Клиентский `contenteditable` преобразуется в JSON,
сервер повторно валидирует и нормализует JSON, после чего самостоятельно
строит обычный текст. Неизвестные блоки, поля и отметки отклоняются.

## Совместимость

Миграция преобразует существующие текстовые черновики в последовательность
абзацев без изменения поля `content`. Старые клиенты могут продолжать
отправлять только обычный текст: сервер построит структурированный документ.

## История

Каждая новая редакция черновика содержит и текстовую, и структурированную
проекцию в снимке `operational-draft-entry.v2`. Ранее созданные неизменяемые
снимки версии v1 не переписываются.

## Интерфейс

Редактор поддерживает полужирное начертание, подчёркивание, два вида списков,
отмену, повтор и очистку форматирования. Вставка и перетаскивание принимают
только обычный текст. Печатная утверждённая форма остаётся неизменной.
