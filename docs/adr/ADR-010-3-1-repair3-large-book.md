# ADR-010.3.1 Repair 3 — крупная электронная книга

## Причина

Предыдущая версия пыталась целиком уместить страницу по высоте окна и
постоянно отдавала часть ширины правой панели. В результате страница и
разворот выглядели как уменьшенные миниатюры, а панель управления
дополнительно сжимала рабочий документ.

## Решение

- одностраничный режим использует почти всю ширину рабочего окна;
- максимальная ширина одной страницы составляет 1650 px;
- страница сохраняет пропорцию A4 `210 / 297`;
- нижняя часть крупной страницы доступна вертикальной прокруткой;
- разворот состоит из двух самостоятельных страниц одинакового размера;
- панель смены и настроек открывается поверх документа;
- закрытая панель не влияет на ширину книги;
- верхняя панель управления является одной цельной строкой;
- ширина граф меняется перетаскиванием вертикальных разделителей;
- точные проценты доступны в выдвижной панели;
- фиксированная пагинация остаётся доступной при прокрутке страницы.

Официальный журнал, зарегистрированные записи и печатная форма не
изменяются.
