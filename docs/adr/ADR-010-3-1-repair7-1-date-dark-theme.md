# ADR-010.3.1 Repair 7.1 — дата inline-записи и тёмная тема

## Проблемы

Inline-создание вызывало обычный маршрут добавления записи без даты.
Сервер создавал запись с текущим временем, после чего браузер пытался
исправить дату автосохранением. Из-за этого мог появляться неверный
дневной заголовок.

В тёмной теме общие стили полей перекрашивали редакторы внутри белого
журнального листа в почти чёрный цвет.

## Решение

- каждая пустая строка хранит дату в форматах `YYYY-MM-DD` и `DD.MM.YYYY`;
- inline-запрос передаёт `event_at` уже при создании записи;
- сервер разбирает дату и передаёт её в `create_draft_entry`;
- некорректная дата отклоняется до создания записи;
- новая запись создаётся сразу с версией 1 и одной ревизией;
- лишний динамический маркер даты удаляется;
- журнальный лист и редакторы используют светлую бумажную палитру;
- оболочка, команды, пагинация и боковая панель следуют выбранной теме;
- активная inline-строка получает отдельную голубую подсветку.

Схема данных и миграции не изменяются.
