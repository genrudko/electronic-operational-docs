# ADR-008.1: промежуточная зона импорта и предварительный просмотр

## Статус

Принято для независимого демонстрационного прототипа.

## Решение

CSV и XLSX сначала загружаются в отдельный контур `apps.imports`.
Импорт не создаёт и не изменяет записи действующих справочников организации,
оборудования и управления.

Для каждой попытки сохраняются:

- исходное имя, размер, формат и SHA-256 файла;
- исходные значения ячеек;
- нормализованные значения отдельно от исходных;
- структура колонок и распознанные общеупотребительные заголовки;
- состояния строк и замечания;
- журнал загрузки, разбора, ошибки и удаления из рабочего списка.

Исходные байты файла после разбора не хранятся. Формулы XLSX не выполняются,
а сохраняются как текст. Полные дубли отмечаются конфликтами. Пустые строки
отклоняются. Физическое удаление попытки импорта запрещено: пользовательское
удаление переводит попытку в состояние `DISCARDED`, сохраняя аудит.

## Ограничения этапа

Patch 008.1 не содержит сопоставления с конкретными моделями и публикации.
Они проектируются отдельно в Patch 008.2 и Patch 008.3.
