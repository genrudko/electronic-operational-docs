# ADR-009.1: базовый реестр документации рабочего места

## Статус

Принято для демонстрационного прототипа.

## Контекст

Оперативному персоналу требуется утверждённый перечень документации, относящийся к конкретному рабочему месту. Перечень должен различать типовые и локальные позиции, фиксировать обязательность, применимость, форму хранения, нормативное основание и периодичность пересмотра. Историческая редакция не должна изменяться после утверждения.

## Решение

Создаётся отдельный модуль `apps.workplace_docs` со стабильной карточкой перечня, версионируемыми редакциями и позициями состава.

Утверждённая редакция:

- связана с рабочим местом и организацией;
- содержит типовые и локальные позиции;
- хранит обязательность и текст применимости;
- различает бумажную, электронную и смешанную форму;
- может ссылаться на нормативный документ;
- получает серверное время, утверждающего сотрудника, дату следующего пересмотра и SHA-256;
- становится неизменяемой вместе со своими позициями;
- создаёт неизменяемое событие аудита.

Для утверждения на сервисном уровне требуется прямое действующее назначение роли `organization_admin`. Замещение не используется как основание утверждения.

## Граница Patch 009.1

Пользовательский интерфейс предоставляет только просмотр утверждённых редакций своей организации. Создание черновиков, редактирование состава и отдельное подтверждение утверждения будут реализованы следующим этапом Patch 009.2.

## Демонстрационные данные

Команда `seed_demo_workplace_documents` создаёт один обезличенный перечень для рабочего места сменного персонала и семь синтетических позиций. Реальные локальные документы и производственные реквизиты не используются.
