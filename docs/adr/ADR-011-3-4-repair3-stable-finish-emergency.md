# ADR 011.3.4 Repair 3 — устойчивое завершение ввода и аварийная отметка

## Решение

1. Аварийная отметка является отметкой всей записи и переключается независимо от
   выделения текста.
2. В меню предусмотрена явная команда снятия аварийной отметки с записи.
3. Красная обводка времени имеет приоритет над общими focus/hover-стилями во всех
   темах.
4. Завершение по Ctrl+Enter и клику вне полотна передает визуальный якорь строки
   в workspace.
5. Сортировка и пагинация при завершении выполняются без smooth-scroll и после
   них восстанавливается положение строки.
6. Всплывающие редакторские панели исключены из outside-click завершения.
7. Ошибки нормативных действий показываются внутри меню, без blocking alert.

## Ограничения

- Схема БД не меняется.
- Схема редактора остается `operational-draft-editor.v4`.
- Официальные записи журнала не изменяются.
