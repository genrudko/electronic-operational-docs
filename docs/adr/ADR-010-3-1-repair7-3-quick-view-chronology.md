# ADR: Patch 010.3.1 Repair 7.3 — быстрый вид и хронология

## Решение

1. Пустая журнальная строка содержит явную кнопку `+`; один щелчок начинает локальное создание записи. Кнопка `+ Запись` в командной панели сохраняется.
2. В боковой панели доступны визуальные переключатели темы (`Авто`, `Светлая`, `Тёмная`) и ширины страницы (`Обычная`, `Широкая`, `Полная`). Выбор применяется сразу и сохраняется в `InterfacePreference` через существующий маршрут настроек журнала.
3. Рабочие черновики отображаются по `event_at`, затем по позиции и идентификатору. После изменения даты или времени браузер перестраивает строки, открывает нужную страницу и кратко подсвечивает перемещённую запись.
4. Перестановка DOM не выполняется во время набора текста: она откладывается до завершения редактирования либо явного применения даты.
5. Официальный журнал, чистовик, модели, миграции и презентационная база не изменяются.
