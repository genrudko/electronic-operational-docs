# ADR-006.2: очистка истории репозитория и защита финализации

- Статус: принято
- Дата: 2026-07-15
- Базовая линия: Patch 006.1

## Проблема

После Patch 006.1 в Git были ошибочно добавлены экспорты чатов, полный план проекта
и реальные рабочие инструкции. Последующий commit удалил их из текущего дерева и
добавил `.gitignore`, но обычное удаление не удаляет содержимое из предыдущих
commit. Одновременно GitHub сообщил публичную видимость репозитория, хотя проектная
документация считала его закрытым.

Предыдущая версия `git_finalize_patch.py` применяла allowlist только к новым
неотслеживаемым файлам. Уже отслеживаемый посторонний файл мог быть повторно
добавлен командой `git add -u`.

## Решение

1. Перед переписыванием истории репозиторий переводится в режим `private` и это
   проверяется через GitHub CLI.
2. Полная исходная история сохраняется во внешний приватный Git bundle, который
   не находится внутри проекта и не может быть автоматически закоммичен.
3. `git-filter-repo` удаляет из всех достижимых commit:
   - каталог `Инструкции/`;
   - `ChatGPT-*.md`;
   - `EOD_full_project_plan_v2_*.md`.
4. После проверки тестов и gate очищенная ветка отправляется единственным
   `--force-with-lease`, привязанным к точному прежнему SHA удалённой ветки.
5. После успешной отправки локальные reflog и недостижимые объекты очищаются.
6. Git-helper проверяет allowlist для любого staged-пути, а не только для новых
   файлов, и отказывается работать с публичным репозиторием.
7. Офисные документы, PDF и архивы по умолчанию запрещены в кодовом репозитории.

## Последствия

- SHA всех прежних commit изменяются, потому что история переписана.
- Старые локальные клоны нельзя отправлять в GitHub; их нужно удалить либо заново
  клонировать очищенный репозиторий.
- Внешний bundle содержит прежнюю чувствительную историю. Его нельзя отправлять в
  облако, прикладывать к обращению или хранить в общедоступном месте.
- GitHub может временно сохранять недостижимые объекты во внутренних кэшах, но они
  больше не доступны через ветки и находятся в закрытом репозитории.
- После Patch 006.2 обычный force-push снова запрещён.
