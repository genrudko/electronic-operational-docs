# ADR-010.3.1 Repair 6 — пагинация по количеству записей

## Уточнение пользовательской модели

Параметр страницы означает количество журнальных записей, а не
абстрактных единиц высоты. Одна многострочная запись остаётся одной
записью и не разрывается между страницами.

## Решение

- настройка называется «Записей на странице»;
- доступны `Авто`, 10, 15, 20, 25, 30 и значение 5–50;
- значение по умолчанию — 15 записей;
- страницы формируются простым разбиением списка по количеству записей;
- фактическая высота каждой записи определяется её содержанием;
- высота страницы рассчитывается браузером по реальному содержимому;
- вертикальный `overflow: hidden` и фиксированная высота удалены;
- последняя страница дополняется пустыми журнальными записями;
- пустая правая страница разворота получает такое же число ячеек;
- скрытая измерительная страница больше не используется;
- раздел «Ширина граф» удалён из боковой панели;
- границы граф продолжают изменяться перетаскиванием;
- двойной щелчок по разделителю восстанавливает 14 / 66 / 20;
- на широком экране панель докуется справа ниже главного меню;
- на узком экране панель остаётся выдвижной;
- непрерывный ввод и отложенная перепагинация сохраняются.

Серверная модель черновиков, история редакций, официальный журнал,
база данных и печатная форма не изменяются.
