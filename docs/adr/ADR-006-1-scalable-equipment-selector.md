# ADR-006.1: масштабируемый выбор оборудования

- Статус: принято
- Дата: 2026-07-15
- Базовая линия: Patch 006

## Проблема

Обычный HTML-список множественного выбора загружает весь реестр в страницу.
При тысячах единиц оборудования поиск и выбор становятся непригодными для
оперативного персонала, а размер HTML и время построения формы растут линейно.

## Решение

1. В форме документа хранится только набор проверенных сервером идентификаторов.
2. Оборудование загружается отдельным GET-запросом порциями по 50 записей.
3. Поиск работает по коду, техническому и диспетчерскому наименованию и алиасам.
4. Предусмотрены фильтры по энергообъекту, категории и виду оборудования.
5. Категории показываются отдельными русскоязычными кнопками.
6. Выбранные позиции не теряются при смене фильтра, поискового запроса или страницы.
7. Чужое оборудование отсекается queryset формы и серверной областью организации.
8. При ошибках других полей формы выбранный состав сохраняется.
9. В браузер не передаётся весь реестр, поэтому механизм масштабируется на тысячи
   и десятки тысяч записей без изменения модели данных.
10. Реестр остаётся источником истины; селектор не создаёт собственных копий
    диспетчерских наименований до регистрации документа.

## Граница

Патч не реализует импорт XLSX/CSV и массовое назначение оборудования. Эти операции
относятся к последующему этапу импорта справочников.
