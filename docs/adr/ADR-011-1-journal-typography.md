# ADR-011.1 — экранная типографика оперативного журнала

## Статус

Принято для демонстрационного прототипа.

## Контекст

После Patch 010 оперативный журнал получил устойчивое рабочее представление,
пагинацию по количеству записей, режим страницы и разворота, тёмную тему,
быстрые настройки ширины и хронологическую перестановку записей.

Для продолжительной работы за смену требуется персонально менять размеры
разных элементов журнала. Один общий размер недостаточен: текст записи,
время, заголовки дат, шапка таблицы и заголовок журнала имеют разные
визуальные задачи.

При этом утверждённая форма и печать не должны зависеть от персональных
экранных предпочтений.

## Решение

1. Существующее поле `journal_font_size` остаётся размером текста записей.
2. В `InterfacePreference` добавляются отдельные поля:
   - `journal_time_font_size`;
   - `journal_date_font_size`;
   - `journal_table_header_font_size`;
   - `journal_title_font_size`.
3. Для всех размеров используются четыре контролируемых пресета:
   `SMALL`, `NORMAL`, `LARGE`, `EXTRA_LARGE`.
4. Боковая панель смены получает:
   - общий пресет для всего журнала;
   - отдельные компактные переключатели каждого элемента.
5. Настройки применяются сразу, сохраняются персонально через существующий
   endpoint отображения и вызывают повторный расчёт экранной раскладки.
6. Зарегистрированный журнал использует те же персональные экранные размеры.
7. В `@media print` размеры принудительно возвращаются к утверждённой
   печатной типографике.
8. Произвольный ввод размера в пикселях не допускается.
9. Patch 011.1 только создаёт основу панели редактора. Форматирование текста,
   семантические элементы и шаблоны реализуются следующими подпачами.

## Последствия

- оператор может подобрать удобную читаемость без изменения данных;
- настройки одного пользователя не влияют на другого;
- печатная форма остаётся стабильной;
- существующие значения `journal_font_size` сохраняют смысл и совместимость;
- требуется миграция только для четырёх новых полей персональных настроек.
