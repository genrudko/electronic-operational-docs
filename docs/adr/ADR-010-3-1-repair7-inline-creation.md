# ADR-010.3.1 Repair 7 — создание записи из пустой строки

## Решение

Пустые разграфлённые строки становятся интерактивными только в графе
времени. Двойной щелчок открывает локальную форму новой записи:

- поле времени получает фокус;
- быстрый ввод времени нормализуется (`1720` → `17:20`);
- `Enter` или `Tab` переводит к содержанию;
- `Esc` отменяет форму до создания серверной записи;
- серверная запись создаётся только после содержательного ввода;
- существующий endpoint `add_draft` используется без изменения backend;
- ответ после redirect разбирается, новая строка импортируется в текущий DOM;
- введённые время и содержание сразу сохраняются штатным autosave;
- кнопка `+ Запись` сохраняется как резервный способ.

Пагинация по количеству записей, разворот, автосохранение и ручная
настройка ширины граф не меняются.
