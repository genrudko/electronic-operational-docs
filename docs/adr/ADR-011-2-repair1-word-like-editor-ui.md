# ADR-011.2 Repair 1 — Word-подобный интерфейс редактора журнала

## Статус

Принято как корректирующее решение для Patch 011.2.

## Причина

Первая визуальная реализация контролируемого редактора имела два дефекта:

1. техническое поле `editor_payload` отображалось как обычное многострочное поле и выводило JSON в каждой строке журнала;
2. команды форматирования были размещены в слишком мелкой построчной панели и не соответствовали согласованному интерфейсу Microsoft Word.

## Решение

Редактор получает два уровня управления:

- постоянную компактную mini-ribbon внутри закреплённой командной панели журнала;
- контекстную всплывающую панель рядом с выделенным текстом.

Mini-ribbon содержит группы «Шрифт», «Абзац», «История» и задел «Отметки». Команды работают с активной записью. Всплывающая панель появляется только при непустом выделении внутри редактора и сохраняет выделение при нажатии кнопок.

Технический JSON остаётся полем формы, но принудительно исключается из визуального дерева CSS-правилом `display: none !important` и повторной защитой в JavaScript.

Построчная мини-панель больше не содержит форматирование. В ней остаются только действия самой записи: дата, перемещение и удаление.

## Ограничения

- набор разрешённого форматирования не расширяется;
- произвольный HTML по-прежнему запрещён;
- семантические отметки остаются отключёнными до Patch 011.3;
- печатная форма не меняется.
