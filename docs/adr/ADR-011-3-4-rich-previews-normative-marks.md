# ADR-011.3.4 — содержательные предпросмотры и нормативные отметки

## Статус

Принято для независимого демонстрационного прототипа.

## Основание

Инструкция по ведению оперативной документации требует:

- обводить красным время аварийного события;
- отмечать включение заземляющего ножа и установку переносного заземления красными молниями;
- использовать столько молний, сколько включено ЗН или установлено ПЗ;
- отмечать отключение ЗН и снятие ПЗ синими молниями;
- перечёркивать прежнюю красную отметку синим.

Локальный рабочий порядок уточняет визуальное представление:

- текст включения ЗН или установки ПЗ подчёркивается красной линией;
- после отключения ЗН или снятия ПЗ красная линия сохраняется, а ниже появляется синяя;
- исходная красная молния перечёркивается синим крестом `X`;
- знак ПЗ имеет подпись `ПЗ` сверху, молнию в центре и номер `№…` снизу.

## Решение

### Схема редактора v4

Нормативная отметка хранится в безопасном структурированном JSON, а не в произвольном HTML.

Документ получает список `annotations`. Текстовые сегменты могут ссылаться на отметки по их идентификаторам.

Поддерживаются виды:

- `emergency`;
- `zn_on`;
- `zn_off`;
- `pz_install`;
- `pz_remove`.

Снятие или отключение обязательно содержит ссылку на исходную запись и исходную отметку. Номер обязателен для установки и снятия ПЗ.

### Отображение

- `emergency` формирует красную обводку времени строки;
- `zn_on` и `pz_install` формируют красную молнию и красное подчёркивание текста;
- `zn_off` и `pz_remove` формируют синюю молнию и синее подчёркивание текста новой записи;
- закрытая исходная отметка получает синий `X`;
- исходный текст после закрытия получает вторую синюю линию ниже красной;
- знак ПЗ формируется как `ПЗ` / `ϟ` / `№…`.

### Безопасное форматирование

Белый список форматирования расширяется до:

- полужирного;
- курсива;
- подчёркивания;
- зачёркивания;
- красного текста;
- синего текста.

Произвольные цвета, HTML, CSS и скрипты не сохраняются.

### Предпросмотры связей

Карточка связанного объекта показывает содержательные сведения:

- для записи — дату и время, тип, текст, автора, версию и позицию;
- для оборудования — диспетчерское и техническое наименование, объект, вид, код, класс напряжения и реестровое состояние;
- для сотрудника — ФИО, должность, подразделение и рабочее место;
- для документа — вид, заголовок, регистрационный номер, статус и автора/регистратора.

Технический идентификатор не занимает основную часть карточки и находится в раскрываемом разделе.

## Ограничения этапа

Отметки фиксируют нормативную семантику записи, но пока не меняют автоматически оперативное состояние оборудования. Реестр фактических состояний оборудования реализуется отдельным последующим этапом.
