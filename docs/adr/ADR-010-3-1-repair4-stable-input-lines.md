# ADR-010.3.1 Repair 4 — стабильный ввод и ёмкость страницы

## Проблема

Перепагинация запускалась после каждого изменения текста. Для расчёта
страницы активная строка физически перемещалась между DOM-контейнерами.
Это прерывало автоповтор зажатой клавиши, могло сбрасывать курсор и
мешало непрерывному набору.

Физическая A4-пропорция также не задаёт удобную рабочую вместимость:
при коротких записях на странице оставалось большое неразграфлённое
пространство.

## Решение

- автосохранение выполняется через 1000 мс после последнего ввода;
- каждое новое событие ввода перезапускает таймер сохранения;
- во время фокуса и IME-композиции активная строка не перемещается;
- перепагинация откладывается до выхода из редактора;
- поддерживаются `compositionstart` и `compositionend`;
- количество номинальных строк на странице настраивается;
- доступны `Авто`, 15, 20, 25, 30, 35, 40 и значение 10–60;
- значение по умолчанию — 30 строк;
- длинная запись занимает несколько номинальных строк;
- незанятая часть страницы дорисовывается разграфлёнными строками;
- настройка одинакова для страницы и разворота;
- пагинация находится в потоке документа и не перекрывает записи.

Серверная модель черновика, история редакций, официальный журнал и
печатная форма не изменяются.
