# ADR-005: нормативный реестр и версионируемая конфигурация

- Статус: принято
- Дата: 2026-07-15
- Этап: доверенное системное ядро

## Решение

1. Нормативный документ и его редакции являются разными сущностями.
2. Требования относятся к конкретной редакции.
3. Опубликованная редакция, её требования и контрольная сумма неизменяемы.
4. Связь `требование → функция → автоматический тест → приёмочный сценарий`
   хранится отдельными записями трассировки.
5. Исторические наименования организации имеют периоды действия и публикуются редакциями.
6. Организационная конфигурация хранится в JSON-редакциях с SHA-256, а не зашивается в Python.
7. Кодовые значения остаются стабильными внутри БД, но пользовательский интерфейс показывает
   только русские наименования и контекстную справку.
8. Реальные локальные нормативные документы и конфигурации предприятия не коммитятся в Git;
   в репозитории находятся только вымышленные демонстрационные данные.

## Граница

Patch 005 создаёт нормативный реестр, просмотр и административный интерфейс.
Полноценный мастер импорта, согласования и публикации без участия разработчика относится
к Patch 008. До официального пилота реестр остаётся частью независимого прототипа.
