# ADR-008.2 — сопоставление колонок и ручная проверка импорта

## Статус

Принято для демонстрационного прототипа. Публикация данных в действующие справочники не входит в Patch 008.2.

## Контекст

Patch 008.1 создал изолированную staging-зону для CSV/XLSX, сохраняющую исходные и нормализованные значения. Следующий безопасный шаг — дать пользователю возможность определить смысл колонок, проверить строки и зафиксировать предварительные решения, не меняя рабочие реестры.

## Решение

1. Для каждого назначения импорта используется явный каталог допустимых полей с обязательностью, типом и ограничениями.
2. Каждая исходная колонка может быть сопоставлена не более чем одному полю. Неиспользуемые колонки явно игнорируются.
3. Подтверждение сопоставления создаёт новую редакцию mapping и пересчитывает все строки.
4. Проверка разделяет:
   - ошибки обязательности, формата и ссылок;
   - дубли внутри файла;
   - конфликты с действующими реестрами;
   - замечания исходного разбора.
5. Пользователь может предварительно принять, отклонить или исправить строку. Исправления хранятся отдельно от неизменяемых исходных значений.
6. Изменение сопоставления сбрасывает прежние решения, поскольку изменяется смысл строк.
7. Каждое индивидуальное и массовое решение фиксируется в аудите. События аудита неизменяемы и физически не удаляются.
8. Patch 008.2 не содержит URL, сервиса или кнопки публикации. Счётчики действующих реестров проверяются gate до и после сценария.

## Каталоги полей

### Организация и персонал

Табельный номер, фамилия, имя, отчество, подразделение, должность, дата начала работы, признак активности.

### Оборудование

Стабильный код, техническое и диспетчерское наименования, вид оборудования, энергообъект, состояние, класс напряжения, дата ввода.

### Управление и ведение

Код оборудования, вид отношения, субъект, уровень, период действия, признак информационного ведения, документ-основание.

### Другой справочник

Ключ, наименование, состояние, примечание.

## Ограничения

- Решение «принято предварительно» не означает публикацию.
- Массовая операция ограничена 100 строками за запрос.
- Конфликтные и ошибочные строки нельзя принять без исправления.
- Исходный файл после разбора не хранится.
- Проверки ссылок используют только справочники той же организации.

## Следствия

Patch 008.3 сможет использовать только предварительно принятые строки и отдельный контур публикации с дополнительным подтверждением, неизменяемой редакцией и аудитом. До реализации Patch 008.3 никакая запись из staging-зоны не может стать рабочей записью.
