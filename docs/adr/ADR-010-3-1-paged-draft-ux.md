# ADR-010.3.1 — страничный вид сменного черновика

Рабочий черновик отображается как электронная книга, а не бесконечная
лента карточек.

Поддерживаются одна страница и разворот, компактная навигация, поиск,
фильтрация, дата при смене суток, быстрый ввод времени без двоеточия,
быстрый ввод даты без разделителей, автоувеличение поля записи,
автосохранение без большой кнопки, ненавязчивая нумерация и контекстная
мини-панель.

Полный редактор форматирования, нормативные значки и шаблоны относятся к
следующему этапу. Официальные записи и утверждённая печатная форма не
изменяются.
