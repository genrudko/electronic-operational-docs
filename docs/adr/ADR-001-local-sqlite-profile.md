# ADR-001: локальный SQLite-профиль разработки

**Статус:** принято  
**Дата:** 14.07.2026

## Контекст

На рабочей станции разработчика отсутствует Docker, поэтому PostgreSQL-профиль bootstrap
не может быть запущен локально. Django-проект и зависимости установлены успешно.

## Решение

Добавить два режима:

- `DB_ENGINE=sqlite` — локальная разработка интерфейса и базовой бизнес-логики;
- `DB_ENGINE=postgresql` — целевая среда, интеграционные и конкурентные тесты, пилот.

SQLite является временным инструментом разработки, а не изменением целевой архитектуры.

## Ограничения

На SQLite нельзя окончательно принимать:

- конкурентную сквозную нумерацию;
- блокировки и параллельные транзакции;
- промышленную неизменяемость;
- backup/restore целевой среды;
- нагрузочные и отказоустойчивые тесты.

Перед Stage 2/3 должен быть доступен PostgreSQL-стенд, локальный или серверный.
